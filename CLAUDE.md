## Rules

### Language split
- **Backend:** Rust only. No Python, no Node.js at runtime.
  - **One exception (owner, 2026-11-10, D11):** `crates/foreman-bambu-helper/` may contain one C++ glue file (built by the `cc` crate) that loads Bambu's prebuilt network plugin, the way OrcaSlicer does. All logic stays in Rust; no other crate links C++. See doc 05 Phase 2C.
- **Frontend:** Vite + React + TypeScript. Styled exclusively from Fieldwork (`frontend/src/design/tokens.css` / `frontend/src/design/DESIGN.md`). No Tailwind, no other UI kit, no hardcoded hex.

### Fieldwork design system
- `frontend/src/design/DESIGN.md` — the authority for all UI decisions.
- `frontend/src/design/tokens.css` — only source of CSS variables (`--fw-*`). Never hardcode hex or other values.
- `frontend/src/design/AGENTS.md` — agent-specific guidance for the design system.
- Do **not** modify these three files; they are copied unmodified from `Hellsparks/Fieldwork-designtemplate`.
- Support all 4 schemes (fieldwork / vector / foundry / olive) × light/dark via `data-fw-theme` / `data-fw-mode` on `<html>`.
- No per-printer custom themes (Mainsail CSS scraping removed per D6).

### Commits
- Run before every commit: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --all`, frontend `npm run build` + tests if touched.
- Small commits — one checkbox (or a cluster) per commit.
- Use `cargo fmt-check`, `cargo lint`, `cargo check-all` aliases (see `.cargo/config.toml`).

### Code quality
- No `unwrap()` / `expect()` in server code paths. Errors via `thiserror`; logs via `tracing`.
- Errors propagate as `AppError` from `foreman-core`.

### Shell compatibility
- Dev machine: CachyOS, fish shell, Wayland, NVIDIA. Second machine: Windows 11.
- Every command in docs and README must work in **fish** and on Windows.
- Use `cargo` aliases and `npm` scripts — no bash-only scripts, no `export VAR=…`.

### Reference repos (read-only, in `vendor/`)
- `vendor/foreman-overview/` — old Node app. Read for behaviour only; never copy its structure.
- `vendor/fieldwork-designtemplate/` — design system source.
- `vendor/spoolman-upstream/` — Spoolman v0.27.1 reference implementation.
- `vendor/` is gitignored and not committed. Cloned locally for reference.
